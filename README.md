# Модуль 2 — Jetpack Compose

Учебный Android-проект по заданиям модуля 2. Каждый пример находится в отдельном файле,
главный экран позволяет выбрать задание.

## Запуск

Открыть эту папку в Android Studio, дождаться синхронизации Gradle и запустить модуль `app`.
Нужны JDK 17, Android SDK 35 и устройство с Android 8.0 или новее.

## Задания 1–5

- `HelloTask.kt`: приветствие с nullable-параметром и три `@Preview`.
- `TextTask.kt`: строковый ресурс и три варианта оформления текста.
- `ButtonTask.kt`: кнопка с рамкой, скруглением и тенью 4 dp.
- `InitialsTask.kt`: серый контейнер 100 dp и круг с инициалами.

Задание 1 собирается в двух вариантах:

```sh
./gradlew assembleDebug -PgreetingName=Android
./gradlew assembleDebug
```

Во втором варианте в `Hello` передаётся `null`.
Для задания 2 открыть `HelloTask.kt` и панель Preview: portrait, landscape и round.

## Стиль кода

Используются осмысленные имена, отступы в четыре пробела, строковые ресурсы,
отдельные компоненты интерфейса и форматирование ktlint.

```sh
./gradlew ktlintFormat
./gradlew ktlintCheck lintDebug assembleDebug
```

## Задания 6–10

- `CircleTask.kt`: исходный и растянутый векторный круг.
- `ContactsTask.kt`: контакт, список контактов и строка с изображением.
- `water/WaterProgress.kt`: расчёт выпитого объёма и серии дней.
- `water/WaterTracker.kt`: интерфейс трекера воды.
- `WaterTrackerUiTest.kt`: UI-тесты задания 9.
- `cart/Cart.kt`: модель корзины и вычисление суммы.
- `cart/ShoppingCart.kt`: добавление, удаление и уведомление о доставке.

Данные контактов демонстрационные. `rememberSaveable` сохраняет состояние при
пересоздании Activity и восстановлении сохранённого состояния; отдельная база
данных и долговременная история потребления воды в задании не предусмотрены.

## Проверка

```sh
./gradlew ktlintCheck testDebugUnitTest lintDebug assembleDebug
./gradlew connectedDebugAndroidTest
```

Для второй команды нужен запущенный эмулятор или подключённое Android-устройство.
Тесты охватывают границы 1500 мл и 500 рублей, сброс серии дней, пустую корзину
и восстановление состояния интерфейса. Версии библиотек зафиксированы для
воспроизводимой сборки; Lint может сообщать о доступных обновлениях.
